Functional Psychology

Functional Psychology describes personality through two complementary functional vectors:

1 → A / B
Expansion · creation · search · development

0 → C / D
Stabilization · preservation · mastering · implementation

E → disintegration state
E is not an independent natural psychotype, but a state of functional disruption or loss of integration.

A central principle of the system is that personality becomes fully understandable not only through the individual psychotype, but through interaction between different functional architectures.

Functional Diagnostics

The applied diagnostic model studies:

* underlying functional psychotype
* current psychological state
* integration and disintegration
* compensatory mechanisms
* interpersonal dynamics
* developmental potential
* organizational behavior

Development does not mean changing the original psychotype.

Psychotype ≠ role ≠ skill ≠ psychological state
